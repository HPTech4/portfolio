About this site

This portfolio is itself a piece of work, so it is held to the same standard as everything above it.

  • No framework, no build step. Plain HTML, one stylesheet, one script. What is in the repository is exactly what the browser runs — nothing is compiled, bundled, or generated.
  • Two themes, designed rather than inverted. The dark palette was built against its own background instead of flipped from the light one, and every text and background pair was measured against WCAG AA in both.
  • The motion knows when to stop. Scroll animation runs through GSAP, but the page is never left invisible if it fails to load — it falls back to CSS transitions, and switches off completely for anyone whose system asks for reduced motion.
  • Accessibility is load-bearing, not decorative. Focus rings are never suppressed, every touch target is at least 44px, and form errors are announced per field rather than as a single generic message.
  • It works offline. A service worker caches the shell, so pages you have already visited stay readable with no connection at all.
